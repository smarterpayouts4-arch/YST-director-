# Portability docs

This folder holds **portable foundation doctrine** intended for reuse on other projects.

| Document | Role |
|----------|------|
| [AI_ENGINEERING_FOUNDATIONS_PLAYBOOK.md](./AI_ENGINEERING_FOUNDATIONS_PLAYBOOK.md) | Domain-agnostic playbook: three planes, APS, MCP, living docs, AI control, verification, strength scorecard, porting checklist |

## Authority

- **Portable playbook** (`docs/portability/`) — how to build and transfer the foundation.
- **Live product canon** (`project-knowledge/`) — what is true about *this* product right now.

Do not treat the playbook as a substitute for `CURRENT_STATE.md` or feature doctrine in a concrete repo. When they disagree about the product, Project Knowledge wins.
