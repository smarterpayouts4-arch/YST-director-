## Experience-sufficiency scores (1–10, each anchored)

| Metric | Observable evidence |
|--------|---------------------|
| Owner effort | Required clicks, typed characters, decisions requested |
| Value returned | Count of new structured insights actually rendered |
| Confidence gained | Reviewer rating + unsupported-claims count |
| New insight | Did the system contribute beyond restating the source? |
| Reason to continue | Is the next action and its payoff stated on screen? |

High effort (≥7) with low value returned (≤3) is a UX defect.

2. Company-specific evidenceRefs resolve to non-rejected profile keys

4. Unselected cards never appear downstream
