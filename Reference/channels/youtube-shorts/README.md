# YouTube Shorts Reference Library

**Authority:** advisory — never project truth. Never runtime-imported.

This is the canonical raw HOW library for the YouTube Shorts channel. It teaches *how* to write a later video-generation-ready **prompt**. This product does **not** render video, generate images, or store media.

Canonical Atom always wins claim conflicts. Reference never authorizes topic, evidence, restrictions, or hypotheses.

## Product output (owner lock)

```text
1 Canonical Atom
      ↓
1 coherent YouTube Short
      ↓
EXACTLY 7 connected scenes
      ↓
each scene designed for ~7 seconds
      ↓
7 image-first / motion-ready prompt packages
      ↓
EXTERNAL generator
```

Scene **count** and ≈7s are product law. Scene **roles** stay flexible.
