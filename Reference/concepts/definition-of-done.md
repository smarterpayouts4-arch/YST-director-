# Definition of Done

Without a definition of done, agents either stop early or iterate forever.

## Product DoD (MVP)

The product is done for a project when:

- Owner confirmed material company fields
- Interview decisions resolved (or max questions reached)
- Research brief approved
- Final prompt passes structural + semantic validation
- Prompt can be copied and downloaded as Markdown
- State is `PROMPT_EXPORTED` / `COMPLETE`
