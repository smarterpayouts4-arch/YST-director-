# Ethical TARI Interview UX

Use Trigger → Action → Reward → Investment to reduce owner confusion — **not** to create compulsive behavior.

| Stage | Interview meaning |
|-------|-------------------|
| Trigger | Show a sharp observation from company data |
| Action | Ask one material question |
| Reward | Reflect how the answer sharpens strategy |
| Investment | Save into the growing research brief |

## Do not adopt

- Dark patterns, gamification, variable rewards for addiction
- Endless questionnaires without information gain
