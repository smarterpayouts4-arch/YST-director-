# Living Project Tree

On scan, generate inventories under `project-knowledge/generated/` only:

- indexes (docs, bootstrap, reference)
- maps (routes, schemas, prompts, MCP tools, ownership)
- reports (drift, monolith risk, stale knowledge)

Human doctrine is never auto-rewritten. Generated maps describe code; they do not redefine product scope.
