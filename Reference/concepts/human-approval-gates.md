# Human Approval Gates

AI may identify gaps and propose changes. Humans approve canonical changes.

## Requires human approval

- PRODUCT / ARCHITECTURE / SECURITY / DECISIONS edits
- Permanent learned rules
- MCP write permissions
- Schema meaning changes
- Product scope changes
- Deleting source files

## Safe automatic repairs

- Regenerate indexes/maps
- Format / sort registries
- Remove stale generated entries
