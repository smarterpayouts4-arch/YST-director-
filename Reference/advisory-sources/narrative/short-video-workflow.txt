Step 4: Write each scene in the right order

For each scene, write in this order:

A. Scene purpose

What job is this scene doing?

Examples:

Hook

B. Narration

What exact line is spoken?

This is the most important part because it controls:

timing
story logic
voiceover
C. On-screen text

This should be shorter and punchier than narration.

Rule of thumb:

Narration explains
On-screen text highlights
Visual shows
D. Visual prompt

Describe the image/video needed to support that line.

E. Asset type

Choose image or video

Practical rule: narration, text, and visual should each do different jobs

A lot of people make them all say the same thing.
That gets repetitive.

Better:

Narration

Full idea:

“A friend mentioned magnesium, so I started paying attention to why so many people were talking about it.”

On-screen text

Compressed idea:

“My friend said it helped.
So I listened.”

Visual

Emotional context:

Two women talking in a café, supplement bottle on table, warm daytime social setting.

That’s the structure you want.

A good 7-scene structure for your current set

Here’s a high-level version of how I’d structure this story:

Scene 1 — Hook

Purpose: attention
Narration: Why is magnesium suddenly getting so much attention, especially before bed?

Scene 2 — Social proof

Purpose: relatability
Narration: It first got on my radar because a friend mentioned it, and I started looking into why people keep bringing it up.
On-screen text: My friend said it helped. / So I listened.

Scene 3 — Forms

Purpose: education

Purpose: tension
