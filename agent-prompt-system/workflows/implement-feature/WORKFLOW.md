# Implement Feature

Ship surgical changes within a compiled IntentContract.

1. Require an IntentContract (`taskType: implement`) before large edits.
2. Stay inside Product / AI Control / Engineering Intelligence ownership.
3. Preserve prompt contract and untrusted-data boundaries; do not expand ambition.
4. Prefer narrow modules; avoid MarketMonth / out-of-MVP scope creep.
5. Pair with `test-and-verify`; verify against contract `acceptanceCriteria`.
6. End state: smallest coherent change that satisfies acceptance; evidence labels.
