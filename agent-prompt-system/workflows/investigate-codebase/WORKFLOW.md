# Investigate Codebase

Map owners, sources of truth, and risks before changing code.

1. Read CURRENT_STATE and ARCHITECTURE pointers → canonical docs.
2. Use RPB MCP inventories when available (`rpb_get_route_inventory`, etc.).
3. Identify owners via `ownership-rules.json`.
4. Report findings before proposing edits.
