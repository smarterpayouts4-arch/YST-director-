# Plan Feature

Clarify scope against PRODUCT non-goals before coding — via IntentContract, not a questionnaire.

1. Compile IntentContract with `taskType: plan`.
2. Confirm the change serves the repository product objective (pointer → PRODUCT).
3. Discovery first; ask only if clarification-gate three conditions hold.
4. Call out IR provenance and prompt-contract impacts when relevant.
5. End state: filled IntentContract (scope In/Out, acceptance, unresolved) for handoff to `implement-feature`.
