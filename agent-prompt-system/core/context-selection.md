# Context selection (discovery-first)

1. Discover **only** what the task needs — files, symbols, tests, rules, specs, package scripts, generated maps, FEATURE notes.
2. Open selected workflows' `required_context` stubs under `project-context/`.
3. Treat stubs as **pointers** — read the linked `project-knowledge/` document (or `rpb_read_project_doc`).
4. Prefer RPB MCP inventories when available (`rpb_get_route_inventory`, `rpb_get_agent_bootstrap`, etc.).
5. Carry real identities into IntentContract `projectRefs`.
6. Do **not** dump ARCHITECTURE + all FEATURES + all APIs into every request.
7. Do not load MarketMonth archive doctrine as live truth.

Repo answers repository questions before any clarification ask.
